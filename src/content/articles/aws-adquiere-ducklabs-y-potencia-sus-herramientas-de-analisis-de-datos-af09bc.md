Amazon Web Services ha anunciado la adquisición de DuckLabs, la empresa holandesa creadora de DuckDB, una base de datos analítica de código abierto que se ejecuta localmente y procesa consultas SQL directamente sobre archivos como Parquet, CSV y JSON. Según AWS, DuckDB seguirá siendo de código abierto bajo licencia MIT y su propia fundación independiente.

La compra busca combinar la velocidad de DuckDB en consultas cotidianas (hasta un terabyte) con los servicios empresariales de AWS como S3, Redshift y Athena. Los cofundadores Hannes Mühleisen y Mark Raasveldt continuarán liderando su dirección técnica mientras AWS integra la herramienta con servicios como EMR, Glue y SageMaker.

Lo interesante es que DuckDB funciona tanto localmente como en S3, lo que la hace especialmente rápida para la mayoría de análisis del mundo real. Además, su arquitectura la posiciona bien para trabajar con agentes de IA, que experimentan con datos de forma similar a los humanos.

En paralelo, AWS ha presentado otras novedades: Lambda ahora permite probar versiones previas de Node.js 26 y Python 3.15 antes de su lanzamiento oficial, IoT Core integra InfluxDB nativamente para datos de series temporales, y GameLift Servers añade protección DDoS automática. También destaca Agentic Resource Discovery (ARD), una especificación abierta que facilita descubrir herramientas y recursos de IA distribuidos en múltiples plataformas, funcionando como "un DNS para agentes".
