La pasada semana, Amazon Web Services celebró su cumbre anual de AWS Heroes, reuniendo a expertos mundiales en inteligencia artificial, computación sin servidores y contenedores para colaborar directamente con los equipos internos de producto de AWS.

Entre los anuncios destacados figura la integración de búsqueda web en Amazon Bedrock. Los modelos OpenAI (GPT-5.4, GPT-5.5 y GPT-5.6) ahora pueden consultar información actualizada de internet, lo que permite que las aplicaciones de IA accedan a contenido en tiempo real sin necesidad de salir del entorno seguro de AWS.

Amazon también lanzó runtime instances en Amazon Bedrock AgentCore, ofreciendo mayor control sobre los entornos de ejecución de agentes de IA con rendimiento predecible. Además, DynamoDB ganó capacidades de búsqueda vectorial, permitiendo almacenar y consultar embeddings junto a datos existentes sin necesidad de gestionar bases de datos vectoriales separadas.

En otra frente, AWS Transform está ahora disponible para todos, facilitando a equipos de ingeniería modernizar código heredado mediante automatización continua. Las funciones Lambda también recibieron un empujón: ahora soportan hasta 3.000 Mbps de ancho de banda de red para cargas de trabajo intensivas en datos.

AWS open-sourceó además Dogwood, un lenguaje de gobernanza especializado para agentes de IA. La compañía también anunció soporte para Agent Plugins, una especificación estándar vendedor-neutral que permite empaquetar extensiones de agentes una sola vez para usarlas en múltiples herramientas como Kiro, VS Code o Cursor.

Por último, presentó Kiro Crew, un espacio de trabajo persistente y autoadaptable para flujos colaborativos de desarrollo multi-agente que permite ejecutar varios proyectos en paralelo sin interrupciones.
