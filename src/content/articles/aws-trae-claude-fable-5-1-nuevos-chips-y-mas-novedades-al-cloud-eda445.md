Amazon Web Services ha abierto el acceso a Claude Fable 5.1, el modelo de inteligencia artificial de Anthropic, a través de sus plataformas Bedrock y AWS. Según Anthropic, esta versión está diseñada para tareas complejas que requieren largas sesiones de trabajo: programación, investigación científica y automatización empresarial. El modelo puede encargarse de proyectos completos de software, incluyendo revisión de código y optimización de rendimiento.

AWS ha implementado nuevas políticas de seguridad para este modelo clasificado como "Covered Model". Los datos de usuarios se retienen hasta 30 días con revisión manual por parte del personal de Amazon, en un modo específico llamado `aws_review`. Además, los clientes empresariales pueden usar Enterprise Frontier Safeguards para mantener sus datos en entornos en la nube controlados.

En infraestructura, AWS lanzó Amazon Linux 2027 en preview público, un sistema operativo optimizado para cargas de trabajo nativas en cloud con kernel 7.1 y enfoque en seguridad y rendimiento. También presentó nuevas instancias EC2 R9g y R9gd con procesadores Graviton5, que ofrecen un 25% mejor rendimiento computacional frente a los modelos anteriores, y mejoras de hasta el 35% en aplicaciones web y aprendizaje automático.

Otra novedad es Lambda SnapStart para funciones con imágenes contenedorizadas, que reduce tiempos de arranque a menos de un segundo para cargas latentes. AWS también lanzó el Agent Registry en disponibilidad general, proporcionando un catálogo privado para agentes y herramientas corporativas. Finalmente, Amazon Redshift ahora soporta tablas Apache Iceberg versión 3.
