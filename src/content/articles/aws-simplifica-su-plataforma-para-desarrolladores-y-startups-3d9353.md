Amazon Web Services ha anunciado una nueva versión simplificada de su plataforma dirigida a desarrolladores y emprendedores que quieren comenzar a crear proyectos sin configuraciones técnicas complejas.

La principal novedad es que ahora los nuevos usuarios pueden registrarse directamente con identidades existentes de Google, GitHub o Apple, sin necesidad de tarjeta de crédito. AWS proporciona 100 euros en créditos gratuitos para empezar, y los usuarios pueden comenzar a trabajar inmediatamente en sus proyectos.

El sistema funciona a través de "proyectos", unidades que agrupan una cuenta de AWS con toda la configuración necesaria. Para conectar agentes de codificación (como herramientas de IA), simplemente hay que copiar una línea de código, sin necesidad de aprender gestión avanzada de permisos. Cuando se desea invitar a colaboradores, basta con enviar su correo electrónico, eliminando la necesidad de configurar manualmente controles de acceso.

Tras usar los créditos iniciales, los usuarios pueden activar un plan de pago fijando un límite de gasto mensual comenzando en 20 euros. AWS pausará automáticamente el proyecto si se alcanza ese límite, evitando costes inesperados. Según el anuncio de AWS, con esta aproximación un usuario logró desplegar una API funcional con base de datos incluida en tan solo minutos.

Para acceder a funciones avanzadas de AWS cuando el proyecto escale, es posible activarlas sin migrar datos ni reconfigurar nada.
